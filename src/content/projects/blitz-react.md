blitz-react is a small command-line tool for starting React projects without the usual pile of setup files. The command creates a project directory, chooses a JavaScript or TypeScript template, installs the dependencies, and can initialize a Git repository. It also has an interactive mode for people who do not want to remember the flags.

The generated app uses Vite, React 19, Tailwind CSS v4, ESLint, and a deliberately short folder structure. The package includes templates, a CLI entry point, configuration, generators, and utility code. I designed and maintain the package, wrote the documentation, and published it under the MIT license.
