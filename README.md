# Oguz Kabasakal’s portfolio

A static Astro portfolio with Markdown content, optimized local images, and React islands for media and the 3D gallery. Cloudflare Pages serves the generated `dist/` directory. No database, CMS server, Cloudflare adapter, or runtime secrets are required.

## Develop

Use Node.js **22.23.1** (`.node-version`) and Bun **1.4.2** (`packageManager`).

```sh
bun install --frozen-lockfile
bun run dev
```

Development works without environment variables. To build, copy `.env.example` to `.env` and replace `your-project` with your chosen Pages project name:

```sh
cp .env.example .env
# Edit SITE_URL in .env, then:
bun run build
bun run preview
```

`SITE_URL` must be the stable public HTTPS origin, such as `https://my-portfolio.pages.dev`. Use the same value for Cloudflare Production and Preview builds. The build deliberately rejects a missing URL or the example placeholder so localhost URLs cannot accidentally be published. `CF_PAGES_URL` is not used because individual deployment URLs should not become canonical URLs.

## Verify and deploy

```sh
bun run check
bun run build
```

`build` runs `astro check` before generating the site and sitemap. Commit `bun.lock` with dependency changes. Cloudflare uses a frozen install so dependency drift fails the deployment.

Follow [the Cloudflare Pages deployment and dashboard guide](docs/cloudflare-pages.md) for first deployment, previews, logs, rollback, analytics, and a future custom domain.

## Update content

- Projects: `src/content/projects/*.md`. `published: false` hides a project; `experiment: true` places it under `/experiments/`, otherwise `/work/`.
- Images: keep originals in `src/assets/images/`. Project `cover` and gallery `src` values use paths relative to the Markdown file, such as `../../assets/images/example.png`. Astro’s `<Image>` generates responsive WebP files at quality 80 for cards and previews. React media and 3D galleries receive static WebP URLs generated by `getImage()` during the build.
- Journal: `src/content/posts/*.md`. All journal entries are public; their file names determine their URLs.
- Ordering: `src/lib/project-order.ts`.
- Audio: replace `public/audio/win95_startup.mp3`, then run `python3 scripts/generate-waveform.py` with FFmpeg installed and commit the regenerated `src/data/win95-waveform.json`.

The one-time Payload migration script has been removed. This app builds independently of the old portfolio repositories. The waveform generator remains a maintenance tool and is not run during deployment.

## Image optimization

The site stays fully static. Run `bun run build` to generate images in `dist/_astro/`, then deploy `dist/` to Cloudflare. No R2 bucket, Cloudflare Images subscription, adapter, or runtime image endpoint is needed. Astro currently uses its default Sharp image service; running the project with Bun does not replace that service with `Bun.Image`.

Cards provide several widths without upscaling originals. Media viewers use images up to 1600 pixels wide, cover previews and 3D textures up to 800 pixels. Social sharing keeps the original image format. Review detailed screenshots at full size when adjusting quality or resolution.

For journal content, reference images under `src/assets` with relative Markdown image paths so Astro can process them. In MDX, you can import `Image` from `astro:assets` and pass an imported image to it. Files referenced directly from `public/` are served as supplied.

Image processing happens during builds. Astro can reuse its local image cache on subsequent builds; reuse on Cloudflare depends on the build cache being retained. A local Bun conversion script remains an alternative if build-time processing becomes a problem.

## Styling

Use Tailwind utilities in Astro and React markup for layout, typography, responsive rules, and interactive states. Reuse complete utility strings locally for repeated controls; keep JavaScript selectors on `data-*` attributes and use ARIA variants for control states.

`src/styles/global.css` owns the theme tokens, fonts, document defaults, Markdown typography (`rich-text`), and shared reveal/accessibility behavior. Bespoke keyframes and native range pseudo-elements stay in scoped Astro `<style>` blocks beside their components. Add reusable design values through `@theme` rather than introducing global component classes.
